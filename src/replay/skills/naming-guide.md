---
name: naming-guide
description: Enforces naming conventions for Cangjie code
trigger: when reviewing naming in code
---

Apply these naming rules when reviewing Cangjie code:
1. Type names (classes, structs, interfaces, enums) must use PascalCase.
2. Function and variable names must use camelCase.
3. Constants and top-level let bindings must use UPPER_SNAKE_CASE.
4. Boolean variables and functions must start with is, has, should, or can.
